# 第 1 课：四周学习地图

依据 2026-10-22 的实现。先按 [README](../README.md) 配置 JDK 21、Node 和 pnpm，完成构建；每一步都要求「运行验证 + 阅读源码 + 改动一项能力」。

## 第 1 周：理解工作台与业务闭环

- Day 1：启动核心，在资产中心搜索 `192.0.2.10`，进入详情并创建规则分析；在报告中找到漏洞、知识和工具轨迹。
- Day 2：阅读 V1–V3 H2 迁移、`AssetService`、`ToolSessionFactory` 和 `ToolSession`；比较当前租户的 32 项资产与跨租户 403。
- Day 3：追踪 Vue 路由、`features/assets/api.ts`、共享请求客户端与 `/api/assets/page`，解释服务端分页和筛选恢复。
- Day 4：阅读 `RiskPolicy`，比较 `192.0.2.10`、`192.0.2.20` 和无漏洞 `192.0.2.38`；解释最高 CVSS、暴露面和重要性如何影响教学分数。
- Day 5：创建草稿、修改保存、审批并重新打开；阅读 `TicketService`、唯一约束和版本条件更新，说明 Agent 为什么没有审批工具。

验收：核心测试脚本通过，报告和审批工单在文件库重启后保留。脚本范围与完整验证的区别见[安全与测试](06-安全与测试.md)。

## 第 2 周：手写工具循环与协议验证

- Day 1：阅读 `ModelClient` 与 `FakeModelServer`，画出 `assistant.tool_calls → tool → assistant`。
- Day 2：运行 `CoreIntegrationTest`；核对 `/api/tools` 的实际响应。当前 `parameters` 是数组，先为完整 JSON Schema 编写失败回归，再修复构造，不能把假模型通过当成真实服务兼容证据。
- Day 3：在 Schema 修复并验证后，配置核心 `LLM_API_URL`、`LLM_MODEL` 和需要的密钥，用支持工具的真实模型试验 `mode=llm`。
- Day 4：比较 `java-orchestrator` 与 `llm-request`；尝试跨资产参数、未知工具和不存在的知识编号。
- Day 5：现有上限已含 6 轮、24 次模型请求工具调用、1 MiB 响应、单次 / 总超时和并发容量；在此基础上设计 Token / 费用预算及失败审计。

验收：能说明工具执行由 Java 授权和调度；真实模型记录必须包含名称、版本、请求轨迹和人工核对结果。

## 第 3 周：Spring AI 与知识检索

- Day 1：按 README 设置 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，显式以 `--lab.tool-backend=local` 启动 Agent；对照 OpenAI 兼容 starter 与手写循环。
- Day 2：比较 `.tools(new RequestScopedAssetTools(...))` 与 `.toolCallbacks(provider)`，核对 local 工具名与核心蛇形工具名的差别。
- Day 3：阅读 `KnowledgeService.search` 与目录分页；当前 16 份共享文档有字面检索及 `lab-` 词项加权，没有向量检索。
- Day 4：基于现有 `KnowledgeResponse` record 扩展 chunk、文档版本和可信来源；不要重复实现已完成的类型化改造。
- Day 5：按[检索练习](05-RAG设计与练习.md)设计精确编号召回、引文校验与固定评测集，再选择是否引入向量库。

验收：区分「报告附加了证据」和「模型调用工具后确实收到证据」。

## 第 4 周：MCP 与系统设计

- Day 1：依次启动核心、MCP Server、Agent 的 `mcp` profile；理解 initialize、tools/list、tools/call。
- Day 2：对比 local 与 MCP 的同一 `/ai/analyze` 接口，观察协议与权限检查分布。
- Day 3：模拟 MCP 不可用；当前没有自动回退。分别验证连接失败、工具不可用与调用超时，再设计显式模式切换。
- Day 4：以现有 H2 持久化、乐观锁、调用预算及固定租户隔离为起点，设计真实 IAM、审计、异步任务和可靠外部投递。
- Day 5：完成工作台演示和 fake 模型协议演示；有真实模型记录时再演示其工具选择质量。

验收：能解释 MCP 的工具描述和跨客户端接入价值，也能指出当前未实现的能力。演示脚本见[第 8 课](08-面试与简历.md)。
