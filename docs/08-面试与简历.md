## 常见追问

**Q：你做的是 AI Agent 还是传统规则引擎？**  
A：demo 模式确实是规则编排，用来验证业务与权限；真实 `llm` 模式使用支持 Tool Calling 的大模型调用注册工具，Java
调度外部调用。两种模式刻意分开，避免把固定脚本伪装成 Agent。

**Q：Tool Calling 和 MCP 有什么区别？**  
A：Tool Calling 是模型选择函数并发出调用请求的机制；MCP 统一外部工具发现与调用协议。MCP 工具仍可经由模型 Tool Calling
被选中，Java 决定授权与执行。

**Q：如何保障租户隔离？**  
A：在 Agent 创建工具前检查目标资产；每个工具执行时再验 IP 范围。生产版应使用可信认证上下文和数据库租户隔离，不允许模型自己提供认证身份。演示版只做了固定租户和
IP 检查。

**Q：RAG 用的是什么向量库？**  
A：当前源码没有向量库，是关键词检索 + 来源引用的基础练习。计划升级 pgvector + 精确编号检索 + Embedding + 混合召回。不要谎称已经实现向量检索。

**Q：工单如何防重复？**  
A：当前 `analysisId -> ticketId` 内存映射实现教学幂等。真正多节点部署需要数据库唯一键、事务和 Outbox 去重。

**Q：为什么不把风险评分直接交给大模型？**  
A：分级策略需可验证、稳定可复现。模型负责汇总证据和解释，确定性评分与高风险动作由 Java 规则和授权工作流控制。
