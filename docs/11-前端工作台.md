# 第 11 课：前端工作台

核对日期：2026-10-22。Vue / TypeScript 工作台围绕授权资产 → 创建分析 → 核查证据 → 编辑保存草稿 → 人工审批组织页面。视觉规范与令牌分别见 [design.md](../design.md)、[tokens.css](../tokens.css)。

## 页面与路由

| 页面         | Hash 路由              | 作用                                          |
| ------------ | ---------------------- | --------------------------------------------- |
| 工作台       | /#/                    | 当前租户 count、最近报告与待审批记录          |
| 资产中心     | /#/assets              | 搜索、重要性 / 公网筛选、分页                 |
| 资产详情     | /#/assets/:ip          | 业务、负责人、OS、端口、模拟漏洞与最近分析    |
| 新建分析     | /#/analysis/new?ip=... | 授权资产每组 20 条选择、demo / llm 与分析目标 |
| 报告列表     | /#/reports             | 风险 / 模式 / 搜索筛选、分页                  |
| 报告详情     | /#/reports/:id?tab=... | 风险、漏洞、知识、工具轨迹与 JSON             |
| 工单列表     | /#/tickets             | 标题 / IP / 编号、状态 / 风险筛选、分页       |
| 工单详情     | /#/tickets/:id         | 编辑 / 保存、证据、冲突恢复、审批与只读       |
| 知识目录     | /#/knowledge           | 标题 / 关键词 / 正文筛选与分页                |
| 知识详情     | /#/knowledge/:id       | 全文、关键词、模拟来源                        |
| 实验设置     | /#/settings            | 标签页口令、核心连接检查、工具定义与模式帮助  |
| 未知前端路径 | Hash 未匹配路由        | 页面不存在与返回入口                          |

Hash 路由支持刷新，不要求后端对任意 HTTP 路径转发。通用列表默认 10 条，可选 10 / 20 / 50；筛选、分页及报告页 tab 写入路由并随前进 / 后退恢复。新建分析的资产选择分页和未提交输入是页面内状态，不承诺所有表单都自动持久恢复。

当前有 11 个业务页面及一个 404 页面，7 个主导航入口。工作台只查询核心 API；Spring Agent / MCP 是独立实验服务，未接入工作台模式切换。

| 路径                                | 职责                                                   |

## 构建与开发

构建需要 JDK 21、Maven 3.9+、Node ^22.18.0 或 >=24.12.0、pnpm 10.32.1。Maven 自动执行前端冻结安装、契约校验、类型检查和打包；运行已有 JAR 只需 Java。

```powershell
# 仓库根目录，JAVA_HOME 已设为 JDK 21
mvn verify
java -jar offline-lab/target/offline-lab.jar

# 另一终端：热更新
pnpm install --frozen-lockfile
pnpm dev
```

`run-offline.ps1` / `run-offline.sh` 会先 package 再启动。如果只想运行已有构建，用 java -jar；IDEA 直接运行主类前需要完成 process-resources 或更完整构建。

`frontend/dist` 随 JAR 放入 static/。旧原生 HTML 源码被排除，不是当前界面入口。已有 dist 且前端未变时才考虑 `-Dfrontend.skip=true`。`pnpm preview` 预览静态构建，当前 Vite 版本默认继承 server.proxy，仍需核心运行；它不是生产托管服务。完整流程也可直接使用核心 JAR。

## 配置：公开浏览器变量与开发代理分开

| 设置                | 配置位置 / 行为                                           |
| ------------------- | --------------------------------------------------------- |
| VITE_API_BASE_URL   | frontend/.env 或进程环境，默认空字符串 / 同源；构建时注入 |
| VITE_API_TIMEOUT_MS | 同上，默认 150000ms，必须为正数                           |
| LAB_DEV_API_URL     | 启动 Vite 的进程环境，默认 http://127.0.0.1:8080          |
| 实验口令            | 页面 sessionStorage，默认 learn-agent-local；设置页可修改 |
| 模型密钥与地址      | Java 服务配置，浏览器设置页不写入这些配置                 |

当前 vite.config.ts 直接读 process.env，没有调用 loadEnv；仅把 LAB_DEV_API_URL 写进 frontend/.env 不会配置启动时代理。示例：

```powershell
$env:LAB_DEV_API_URL = 'http://127.0.0.1:18080'
pnpm dev
```

Vite 的配置加载时机见[官方说明](https://vite.dev/config/#using-environment-variables-in-config)。只有 VITE_* 经 import.meta.env 注入浏览器；其值公开，不能放密钥。[示例文件](../frontend/.env.example)已按此区分。

当前推荐同源或 Vite 代理；设置跨域绝对 API 地址需要另外处理服务端 CORS，仓库没有提供通用跨域部署配置。前端 150s 等待覆盖默认 120s 模型阶段，但不构成整个请求成功保证。取消、离开或超时后应从报告列表确认后端是否已保存。

## API 与状态

完整参数和大小写见[第 3 课](03-API与运行示例.md)。前端使用 dashboard、assets/page、analyses/page、tickets/page、knowledge/page / {id}，以及原有详情 / 分析 / 编辑 / 审批接口。

统计对租户业务表执行数据库 count，知识为共享全表 count。列表 q 用字面子串，原 /api/knowledge?q=... 保持加权检索供工具调用。V3 扩充数据后默认租户 32 资产 / 89 漏洞，详情漏洞来自单资产有界接口，没有真实扫描或导入。数据迁移见[第 12 课](12-模拟数据集.md)。

交互约束：

- loading / empty / error / retry 独立处理，不显示伪造分析进度。
- 使用 AbortSignal 和代次隔离，旧响应不能重写新页面或跳转。
- 未保存禁止审批，离开 / 刷新提醒；409 必须主动重载；已审批只读。
- 口令切换取消请求、清空旧数据并重读；审批码只留页面内存。
- 动态模型 / 知识文本采用 Vue 插值，不渲染任意 HTML。
- 核心健康检查不代表模型可用；设置页显示的核心工具 parameters 当前存在 Schema 缺陷，见核验记录。
- 表格窄屏局部横向滚动，导航在移动宽度折叠，支持可见焦点和减少动态效果。
