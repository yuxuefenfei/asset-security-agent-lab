# 第 6 课：安全边界与回归测试

核对日期：2026-10-22。当前测试数量、运行结果与已知缺陷集中维护在[核验记录](09-核验记录.md)。

## 已落实的工程约束

- 三个 Java 服务默认绑定 127.0.0.1。核心 API 检查 X-Lab-Token；固定租户配置控制资产、报告、工单查询。
- 核心 ToolSession 检查工具白名单、目标 IP、必选字符串和额外字段。Spring / MCP 使用固定 allowed-ip 与检索长度校验，再通过核心做业务授权。
- 资产 / 漏洞在短只读事务中固定快照，模型网络调用在数据库事务外；报告、证据与轨迹原子保存。
- 工单 analysis_id 唯一，草稿创建可重试；编辑与审批通过版本条件更新，审批后只读。
- Flyway V1–V3 初始化与增量升级，不重置已有业务数据；历史报告保留当时资产、漏洞和知识快照。
- 核心请求容量、分页、问题 / 查询长度、模型下载、轮数、工具次数、超时和并发均有限制，具体默认值见[API 文档](03-API与运行示例.md)。独立 Spring Agent 不自动继承核心模型预算。
- Vue 使用共享请求客户端、请求取消与代次检查，动态内容用插值渲染。切换口令后清除旧数据并重读，错误显示 traceId。
- 未保存工单禁止审批；离开 / 刷新有提醒；409 后必须主动重载，已审批草稿不恢复编辑。
- 实验口令保存在标签页 sessionStorage，审批码仅在页面内存；VITE_* 公开配置中不应出现密钥。

## 当前限制

实验口令和审批码不是生产认证，approvedBy 是配置的模拟标识。共享知识没有文档级授权，MCP 协议端点没有生产 IAM。轨迹仅覆盖成功工具调用，不能当成完整持久审计。

核心 `ToolSchemas.definition` 的 parameters 当前是数组而非完整 JSON Schema。运行时参数约束和假模型测试仍存在，但没有验证真实模型是否接受工具定义。真实模型选择、解释和引文质量均未验收。

没有真实扫描、攻击执行、外部工单投递、自动整改和真实漏洞复检；工单 APPROVED 只是本机流程状态。

## 验证命令与范围

使用 JDK 21、项目要求的 Node 与 pnpm，从根目录执行：

```bash
mvn verify
pnpm format:check
pnpm exec playwright install chromium
pnpm test:ui
```

Maven 自动构建前端；其 `verify` 包含：

| 测试 / 检查              | 验证内容                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| ContractTest             | record、稳定枚举、包装与严格类型                                                                             |
| CoreIntegrationTest      | 实际 HTTP、口令与租户、资源、目录筛选 / 分页、快照、草稿与并发、假模型协议 / 容量 / 超时、扩充数据与健康资产 |
| RiskPolicyTest           | 封顶、等级阈值与空漏洞                                                                                       |
| RestartPersistenceTest   | 临时文件库先执行 V2，创建报告 / 审批工单并修改资产，再升级 V3，验证保留与再次重启不重复插入                  |
| AgentControllerTest      | 模型前校验、MCP 回调接入、模型错误及 traceId                                                                 |
| McpServerIntegrationTest | 真实 Server / SDK 初始化、发现、资产 / 漏洞 / 知识调用与越权拒绝，核心使用 stub                              |
| WorkflowSmokeIT          | 打包后三服务 local / MCP 完整链路；OpenAI 兼容 HTTP 假模型，每种模式两轮与三个工具结果                       |
| Spotless                 | Java / POM 格式；不手改 APT 生成源码                                                                         |

核心脚本 `test-offline.ps1` / `test-offline.sh` 仅运行契约与核心 test 阶段，不含 Spring 模块、打包链路、Spotless verify 或浏览器回归。`run-offline` 会重新 package 并启动核心，不是单纯启动已打包 JAR。

浏览器测试单独运行，自动启动已构建核心 JAR，使用随机回环端口和隔离内存库；覆盖跨页面编辑 / 保存 / 审批 / 历史、冲突、旧响应隔离、文本转义、未保存导航、分页 / 回退、错误重试、口令切换和移动布局。测试结束关闭自己创建的服务与浏览器。浏览器取消 HTTP 等待不代表服务端任务回滚，超时后应先查报告列表。

报告路径：各模块 `target/surefire-reports/`，MCP 模块 `target/failsafe-reports/`；子服务日志和浏览器截图位于 `offline-lab/target/`。`LAB_BROWSER_CHANNEL=chrome` 或 `msedge` 可使用本机已安装浏览器。

## 后续核验

真实模型工具定义兼容、工具选择和引文正确性；真实身份、审批审计和文档授权；外部投递幂等、生产容量、迁移回滚与备份恢复，需要随实现单独验收。fake / mock 测试不能代表这些能力已完成。
