# 第 6 课：安全边界与回归测试

## 1. 当前落实的边界

- 三个服务默认绑定本机回环地址。核心 API 使用实验口令；核心 ToolSession 验证固定租户、目标 IP、白名单、字符串参数并拒绝额外字段。Spring/MCP
  适配层限制授权 IP 和查询长度，业务授权由核心再次检查。
- 资产/漏洞在短只读事务中固定本次快照。规则计算分数，模型只能解释和申请只读工具；模型网络调用不占用数据库事务。
- 同一分析的工单有数据库唯一约束；草稿创建可重试，编辑和审批通过事务与版本条件更新。审批后内容锁定。
- 分析快照、知识证据、工具轨迹和工单保存在 H2。Flyway 保证初始化不会在重启时覆盖业务记录。
- 请求、查询词、问题、分页大小、模型响应下载、模型轮数和工具次数均有限制；模型请求有单次/总超时，并发分析容量可配置。
- 页面取消旧请求并校验响应归属；保存修改后才允许审批。已审批草稿重新加载不会解锁按钮。动态文本转义，错误显示请求编号。
- Spring Agent/MCP 的核心客户端为类型化响应，并配置连接与读取超时；共享 API 枚举使用稳定字符串，数据库不存枚举序号。

实验口令与审批码仍是教学机制，`approvedBy` 是配置的模拟标识。知识库仍为共享虚构资料，没有真实身份系统、文档级授权或外部工单同步。模型解释和引文质量需另行用真实模型评测。

## 2. 可复现的测试

从根目录执行：

```bash
mvn clean verify
```

- `ContractTest`：record JSON、枚举代码、成功包装与错误编号。
- `RiskPolicyTest`：评分封顶、阈值边界和空漏洞。
- `CoreIntegrationTest`：实际 HTTP 参数/口令/租户、资源、分页、快照、草稿编辑、版本、并发创建/编辑/审批、模型协议和下载/超时预算。
- `RestartPersistenceTest`：临时 H2 文件库关闭并重新启动应用，验证已审批记录与报告快照恢复，已修改资产没有被种子数据重置。
- `AgentControllerTest`：校验与越权发生在模型之前、MCP 回调注入、模型错误及 traceId。
- `McpServerIntegrationTest`：真实 MCP 初始化、工具发现、类型化资产/漏洞/知识调用和越权拒绝。
- `WorkflowSmokeIT`：Maven Failsafe 自动启动已打包的三个服务，通过 fake Ollama 验证 local/MCP 各两轮、三个工具结果；核验后关闭自己创建的子进程。
- `spotless:check`：verify 中执行 Java/POM 格式检查。生成的 APT 源码不在手工格式检查范围内。

仅核验核心可运行 `bash ./scripts/test-offline.sh` 或 Windows 的 `./scripts/test-offline.ps1`；脚本构建共享契约和核心。完整跨服务测试使用根目录
verify。Java 报告位于各模块 `target/surefire-reports/`，打包链路报告位于 MCP 模块 `target/failsafe-reports/`，子服务日志位于
`offline-lab/target/`。

浏览器测试：

```bash
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm test:ui
```

测试自动创建随机端口和内存数据库，使用独立浏览器上下文，验证预览、编辑、保存、审批、历史恢复、过期版本、陈旧请求隔离及模型文本转义。服务运行本身无需
Node。全部测试只连接各自的本机服务与模拟模型，不使用真实模型密钥。

## 3. 后续适合验证的范围

真实模型的工具选择和引用质量、真实身份与审批审计、外部工单幂等同步、长期数据保留与生产备份恢复，需要随对应功能一起实现和核验。当前
fake/mock 测试验证协议与工程行为，不能代表真实安全决策质量。
