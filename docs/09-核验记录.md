## 已知问题与未覆盖项

1. **核心工具 Schema**：`ToolSchemas.definition()` 链式构造最终返回 required 数组。实际 `/api/tools` 的 parameters 是 `["ip"]` / `["query"]`，不是 JSON Schema 对象。现有 CoreIntegrationTest 的工具定义断言不足以发现此问题，fake 模型也未校验。应增加结构回归、修复并联调真实模型；本次文档维护记录了问题，未修改业务实现。
2. **Agent 裸配置**：默认 `lab.tool-backend=mcp`，未启用 profile 时 MCP Client 关闭；必须显式 local 或启用 mcp profile。LLM_BASE_URL、LLM_MODEL、LLM_API_KEY 无默认值，需配置。当前启动示例已与此一致。
3. **模型与检索**：未验证真实模型的工具选择、解释、引文、成本或质量；没有 Embedding、向量库、重排及服务端引文校验。
4. **安全与生产能力**：实验口令、固定租户 / IP 和模拟审批人不是生产 IAM；没有文档级授权、完整持久审计、生产容量或外部工单 / 扫描闭环。
5. **数据语义**：评分考虑全部扫描记录，包括 RESOLVED；无漏洞资产仍可能获得暴露 / 重要性加分。参见第 3、12 课。

## 复现命令

从仓库根目录，使用项目要求的 JDK、Node 与 pnpm：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
java -version
mvn -version
node --version
pnpm --version
mvn verify
if ($LASTEXITCODE -ne 0) { throw 'Maven 验证失败' }
pnpm format:check
if ($LASTEXITCODE -ne 0) { throw '前端格式检查失败' }
pnpm exec playwright install chromium
pnpm test:ui
if ($LASTEXITCODE -ne 0) { throw '浏览器回归失败' }
```

JDK 路径需按本机替换。Bash 使用同名 Maven / pnpm 命令；使用系统 Chrome / Edge 时可设置 LAB_BROWSER_CHANNEL。运行的服务若占用待清理 / 打包 JAR，应先停止对应进程再使用 clean；不要删除数据文件。

Maven -o 只关闭 Maven 下载，pnpm 仍要求已有缓存或网络。测试使用隔离数据库、随机回环端口及本机假模型，不读取实际 H2 业务库，也不以真实模型密钥作为前提。
