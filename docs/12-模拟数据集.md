# 第 12 课：模拟数据集

依据 2026-10-22 的 V1–V3 Flyway 迁移。全部资产、组件、漏洞与知识均为虚构教学资料，使用文档示例 IP 网段；不会向这些地址发起真实扫描。

## 初始化规模

| 数据         | 合计 | 默认 tenant-blue | 隔离 tenant-red |
| ------------ | ---: | ---------------: | --------------: |
| 资产         |   38 |               32 |               6 |
| 漏洞         |  100 |               89 |              11 |
| 公网暴露资产 |   14 |               10 |               4 |

另有 107 条关联端口记录、16 份共享知识。纯新库**不预置分析报告和工单**，这些由用户操作产生；已使用文件库的数量取决于历史操作。

V2 有 3 资产 / 4 漏洞 / 7 端口 / 4 知识。V3 追加 **35 资产、96 漏洞、100 端口、12 知识**，其中 30 项资产属于默认租户、5 项属于隔离租户。默认工作台只显示默认租户资产 / 漏洞，共享知识不按租户过滤。

新增有漏洞资产每项 2–4 条，包含 LOW / MEDIUM / HIGH / CRITICAL，状态 OPEN / VERIFIED / RESOLVED。日期与扫描器是训练字段，verified 不代表真实扫描复核。

新增虚构公告 LAB-2026-0101 至 LAB-2026-0112 分别关联 KB-101 至 KB-112，覆盖网关访问、会话、管理权限、凭据、备份、缓存、队列、共享存储、服务账号、构建、日志和证书等主题。知识来源为 training://，不是官方公告链接。

现有评分考虑所有扫描记录，包括 RESOLVED；无漏洞也可能有公网 / HIGH 重要性加分。例：非公网 LOW 重要性的 .38 为 0 / LOW，而公网无漏洞 .59 默认仍有暴露加分。规则见[第 3 课](03-API与运行示例.md)。

## 初始化与已有库升级

- V1 建表与约束，V2 初始记录，V3 增量追加。
- 首次启动执行三个迁移；已有 V2 文件库运行新版 JAR 时仅追加 V3；再次重启不重复插入。
- 保留原有报告、工单和资产修改，不需删除文件库。
- 不修改已执行迁移；未来扩充用下一版本迁移，保持 Flyway 校验和。
- 内存预览库也要运行包含新版迁移的实例才有新增数据，刷新旧进程页面不会执行新 SQL。

从仓库根目录使用要求的 JDK / Node / pnpm：

```powershell
mvn verify
java -jar offline-lab/target/offline-lab.jar
```

默认文件 `data/asset-security.mv.db`，实际连接 `jdbc:h2:file:./data/asset-security` 依赖工作目录。运行脚本会切根目录，直接 JAR / IDEA 应保持一致；自定义 LAB_DB_URL 使用明确路径。

手动升级前先停止占用目标文件库的服务并备份，再启动新 JAR；不要对运行中的嵌入式 H2 直接复制文件作为可靠备份，也不要同时启动两份进程打开同一文件库。本项目没有自动备份 / 恢复管理页面。

## 数量核对

默认口令下读取当前租户：

```bash
curl -H 'X-Lab-Token: learn-agent-local' 'http://127.0.0.1:8080/api/assets/page?page=1&size=10'
curl -H 'X-Lab-Token: learn-agent-local' 'http://127.0.0.1:8080/api/vulnerabilities?ip=192.0.2.30'
curl -H 'X-Lab-Token: learn-agent-local' 'http://127.0.0.1:8080/api/knowledge/page?page=1&size=20'
```

在隔离测试库或停止服务后由合适 H2 客户端可执行以下只读统计；本项目未启用 Web H2 Console：

```sql
SELECT tenant_id, COUNT(*) FROM lab_asset GROUP BY tenant_id;
SELECT a.tenant_id, COUNT(*)
FROM lab_vulnerability v JOIN lab_asset a ON a.id = v.asset_id
GROUP BY a.tenant_id;
SELECT COUNT(*) FROM lab_asset_port;
SELECT COUNT(*) FROM lab_knowledge;
```

CoreIntegrationTest 验证种子总数、四档严重度 / 三种状态、分页、健康资产和知识关联；RestartPersistenceTest 验证 V2 文件升级和再重启。实际运行结果见[核验记录](09-核验记录.md)。
